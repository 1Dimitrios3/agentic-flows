# 7. DONE

The run is finished: the tickets in `tickets/` are approved. Close it with one message to the human:

1. The path of `tickets/`.
2. The ticket order: each ticket's number and title, with which can run in parallel.
3. Where the final scope differs from the human's brief in `sources/`: one line per difference, naming its decision (D#). With none, say the scope matches the brief.
4. A one-line sign-off, such as "Happy building!"

End the message there: building starts outside this run, on the human's call. Log `done`.

**Done when** the human has the tickets path, the ticket order and the scope differences, and the log's last line is `done`.
